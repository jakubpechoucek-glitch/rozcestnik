Půdorysy Cvrčovice

Web Kód

Interaktivní půdorysy nového domu. Každá věc ve stavbě (dveře, okno, svítidlo…) je klikací bod s detailem.

  • HTML/CSS
  • Vanilla JS
  • JSON data
  • GitHub Pages

Co umí

  • Dvě podlaží a střecha, přepínání pater
  • Vrstvy, které jde zapínat: dveře, okna a vrata, povrchy, nábytek a kuchyně, EZS a kamery, svítidla, FVE, stínění
  • Barvy podle stavu (OK / k ověření / k dořešení)
  • Na mobilu se detail otevře jako panel zespodu

Jak je to postavené

  • Obrázek půdorysu + body umístěné v pixelech obrázku
  • Každá vrstva = jeden soubor v data/*.json, přidat položku znamená upravit JSON
  • Průběh projektu se vede v PROGRESS.md

Tip: s parametrem ?edit se zapne editor souřadnic. Klikneš do půdorysu a vypíšou se pixely pro nový bod, takže body nemusíš měřit ručně.

Stavební deník

Web Kód

Zápisy z kontrolních dnů na stavbě a úkoly, které z nich vyplývají.

  • HTML/CSS
  • Vanilla JS
  • Firebase Firestore
  • GitHub Pages

Co umí

  • Kontrolní dny: kdo byl přítomen, průběh prací, změny
  • Úkoly s odpovědnou osobou a stavem, filtr podle lidí a rolí
  • Souhrnná tabulka a statistiky splněných úkolů
  • Přidání nového kontrolního dne a úprava úkolů přímo na webu

Jak je to postavené

  • Čtyři soubory: index.html, style.css, app.js, data.js
  • Úvodní zápisy jsou v data.js, změny se ukládají do Firestore
  • Firebase se načítá přímo z CDN, nic se neinstaluje

Tip: pro malou aplikaci, kam má zapisovat víc lidí, je Firestore nejrychlejší start: databáze bez vlastního serveru jen se dvěma skripty z CDN.

Byty k pronájmu

Ukázka s demo daty Kód Podrobná dokumentace

Evidence a finanční přehled investičních bytů. Nahradil Excel „Karty bytů“.

  • Vanilla JS
  • Supabase + RLS
  • Python import
  • Node testy
  • GitHub Pages

Co umí

  • Přehled portfolia: hodnota, nájmy, obsazenost, blížící se termíny (konec nájmu, konec fixace)
  • Detail bytu: historie pronájmů, hypotéka, odkazy, grafy
  • Finanční ukazatele: CAGR, yield nominální i reálný, IRR, daňové odpisy
  • Úpravy dat přímo na webu

Jak je to postavené

  • finance.js obsahuje jen výpočty bez práce se stránkou, takže jde testovat (node tools/test_finance.js)
  • data.js ukládá buď do Supabase, nebo do paměti v režimu ?demo
  • Excel se jednorázově převedl skriptem tools/import_excel.py na SQL
  • Osm dokumentů: zadání, rozbor Excelu, datový model, vzorce, nalezené chyby v datech

Tip: mobilní prohlížeče drží staré CSS a JS v mezipaměti. Pomůže přidat k odkazům verzi (app.js?v=abc123) a při každé změně ji zvýšit.

Rodinné finance

Web (přihlášení) Kód

Webová náhrada Excelu „aktiva a pasiva“: majetek, měsíční uzávěrka stavů účtů a investic, plán cash flow.

  • Vanilla JS
  • Supabase + RLS
  • Kurzy ČNB / ECB
  • Export .xlsx
  • GitHub Pages

Co umí

  • Čisté jmění a rozpad na nemovitosti, hotovost, investice a penzijko, graf vývoje
  • Uzávěrka měsíce na jedné obrazovce místo deseti ručních kroků v Excelu
  • Cash flow: plán proti skutečnosti po měsících
  • Export do Excelu, plná záloha do JSON a obnova ze zálohy

Jak je to postavené

  • Stavy se ukládají v původní měně (CZK, EUR, GBP, PHP), přepočet se dělá kurzem daného měsíce
  • Kurzy se načtou z ČNB k poslednímu dni měsíce, záložně z ECB
  • Souhrny se počítají z uložených stavů, nic se nekopíruje mezi sloupci

Tip: do políček jde psát výpočet jako v Excelu, třeba 7585+250537 nebo 20575*eur+80. Opisování z výpisů je pak mnohem rychlejší.

Směnné kurzy

Web Kód

Sledování kurzů CZK ↔ EUR, GBP, PHP, USD s historií za 12 měsíců, portfoliem a alarmy.

  • React + TypeScript
  • Vite
  • Tailwind
  • Recharts
  • Express
  • SQLite
  • Render

Co umí

  • Dashboard s aktuálními kurzy a hodnotou portfolia v Kč
  • Grafy vývoje kurzů za rok, převodník
  • Alarmy při dosažení cílového kurzu

Jak je to postavené

  • Frontend a backend v jednom repozitáři (frontend/, backend/)
  • Kurzy z Frankfurter API: zdarma, bez API klíče
  • Plánovač na serveru pravidelně stahuje kurzy a hlídá alarmy

Tip: Frankfurter je nejjednodušší zdroj kurzů ECB pro hobby projekty, protože nevyžaduje žádnou registraci.

Státní dluhopisy

Web Kód

Kalkulačka výnosů Dluhopisu Republiky: srovnání fixního a protiinflačního dluhopisu podle scénáře inflace.

  • Jeden HTML soubor
  • React 18 z CDN
  • Babel v prohlížeči
  • GitHub Pages

Co umí

  • Výpočet výnosu fixního a protiinflačního dluhopisu
  • Volitelný scénář inflace, srovnání obou variant
  • Přepínání češtiny a angličtiny

Jak je to postavené

  • Celá aplikace je jediný soubor index.html
  • React a Babel se načítají z unpkg, JSX se překládá až v prohlížeči, takže není potřeba žádný build

Tip: React bez buildu je skvělý na rychlý prototyp kalkulačky. Pro větší aplikaci se vyplatí Vite (viz Směnné kurzy).

Morning Briefing

Web Spotify Kód

Automatický denní audio podcast (7–8 minut) o trzích, centrálních bankách, big techu a světových zprávách.

  • Python
  • RSS
  • Claude API
  • edge-tts
  • GitHub Actions
  • GitHub Pages

Jak to funguje

  • Každé ráno se stáhnou zprávy z RSS kanálů a tržní čísla
  • Claude z nich napíše scénář epizody
  • edge-tts ho namluví do mp3
  • Epizoda a feed.xml se commitnou do docs/ a GitHub Pages je zveřejní jako podcast

Jak je to postavené

  • Jeden skript scripts/generate_episode.py
  • Zdroje zpráv a tickery v config/feeds.py, délka segmentů v konstantách
  • Cron v .github/workflows/daily-briefing.yml, API klíč jako secret repozitáře

Tip: podcast je jen RSS soubor s odkazy na mp3. Když ho zveřejníš přes GitHub Pages, odebíráš ho v jakékoli podcastové aplikaci a hosting je zdarma.

Lukas University

Web (přihlášení) Kód Podrobná dokumentace

Výběr vysoké školy v Evropě podle oboru a predikce výsledků IB Diploma. Nahradil srovnávací Excel.

  • React
  • Vite
  • Tailwind
  • Express
  • SQLite
  • JWT
  • node:test
  • Render

Co umí

  • Katalog škol a programů pro čtyři obory
  • Predikce IB ve více scénářích, skóre do 45 bodů se počítá samo
  • U každého programu vyhodnotí, jestli požadavky splňuje ✅, je těsně pod ⚠️ nebo nesplňuje ❌
  • Vážený průměr známek z assessmentů pro každý předmět

Jak je to postavené

  • Backend ve vrstvách: routes → controllers → services → repositories
  • Výpočty v shared/calc sdílí server i prohlížeč, takže vyjde vždy stejné číslo
  • Účty se zakládají při startu z proměnných prostředí, heslo se mění při prvním přihlášení
  • Databáze leží na trvalém disku Renderu

Tip: SQLite na Renderu potřebuje persistent disk, jinak se databáze při každém nasazení smaže.

Rozcestník

Web Kód

Tahle stránka a úvodní rozcestí: odkazy na všechny projekty, backlog nápadů a společné přihlášení rodiny.

  • HTML/CSS
  • Inline SVG
  • Supabase Auth
  • GitHub Pages

Co umí

  • Dlaždice s vlastní SVG grafikou podle obsahu projektu, světlý i tmavý režim
  • Jedno přihlášení (e-mail nebo Google) pro všechny chráněné weby
  • Backlog nápadů s přidáváním a odškrtáváním

Jak je to postavené

  • Všechny weby běží na jakubpechoucek-glitch.github.io, sdílí tedy jeden origin a jedno uložené přihlášení
  • Chráněný web načte /rozcestnik/auth.js a zavolá RodinaAuth.vyzadujPrihlaseni()
  • Členství ověřuje databáze (tabulka členů), ne stránka

Tip: veřejný „publishable“ klíč Supabase smí být v kódu. Bezpečnost zajišťují pravidla v databázi, ne utajený klíč.
